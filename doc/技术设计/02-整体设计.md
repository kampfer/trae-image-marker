# 3. 整体设计

## 3.1 整体架构

采用 Electron 多进程架构，分为主进程、预加载脚本和渲染进程。

## 3.2 渲染进程分层

- 表现层：使用Ant Design和自制react组件开发用户界面，使用PixiJS绘制图片和标注
- 业务逻辑层：使用react redux管理状态，处理标注数据创建、编辑、删除、缩放、旋转、撤销、重做等业务逻辑逻辑
- 数据层：与electron通信，完成文件读写、标记文件序列化/反序列化、图片加载等任务

## 3.3 项目目录结构约定

```
src/
├── components/     # UI组件目录
│   ├── ComponentA/
│   │   ├── ComponentA.tsx
│   │   ├── ComponentA.module.css
│   │   └── index.tsx
│   └── ComponentB/
│       └── ...
├── main/            # Electron主进程代码
│   ├── index.ts           # 主进程入口
│   ├── preload.ts         # 预加载脚本
│   ├── ipc/               # IPC通信处理
│   └── services/          # 主进程服务
├── store/           # Redux状态管理
│   ├── index.ts           # Store配置
│   ├── slices/            # Redux切片
│   ├── selectors/         # 选择器
│   └── serializers/       # 序列化器
├── types/           # TypeScript类型定义
│   ├── electron.d.ts
│   └── css-modules.d.ts
├── assets/          # 静态资源（图片、图标等）
├── App.tsx          # 应用根组件
├── App.module.css   # 应用根组件样式
├── index.css        # 全局样式
└── renderer.tsx     # 渲染进程入口
```

### 目录职责说明

| 目录          | 职责           | 说明                                                                                   |
| ------------- | -------------- | -------------------------------------------------------------------------------------- |
| `components/` | UI组件         | 存放所有React UI组件，每个组件独立文件夹，包含组件源码、CSS Modules样式和index导出文件 |
| `main/`       | Electron主进程 | 存放主进程入口、预加载脚本、IPC处理器和主进程服务                                      |
| `store/`      | Redux状态管理  | 存放Redux Store配置、Slice定义、Selectors和序列化器                                    |
| `types/`      | 类型定义       | 存放全局TypeScript类型声明和接口定义                                                   |
| `assets/`     | 静态资源       | 存放图片、图标等静态资源文件                                                           |

## 3.4 设计原则

1. **单一职责原则**：每个服务只负责一类数据操作
2. **接口隔离原则**：提供最小化的接口，避免不必要的依赖
3. **依赖倒置原则**：依赖抽象接口而非具体实现
4. **开闭原则**：对扩展开放，对修改关闭
5. **里氏替换原则**：子类可以替换父类而不影响程序正确性

# 5. 代码约定

1. 表现层action全部来自业务逻辑层，不重新定义。
2. 开发模式下 Redux 状态发生变化时打印日志，日志应包含触发变更的 action 及变更前后的状态；生产模式下不输出此类调试日志。
